# Sistema de puntos de juego

Este proyecto implementa un módulo funcional e independiente en Java diseñado para registrar, almacenar y actualizar el puntaje de un jugador en base a sus condiciones de victoria dentro del juego.

## 🚀 Funcionalidades
* **Encapsulamiento de Datos:** Control seguro del puntaje del jugador mediante atributos privados y métodos de acceso (`Getters`).
* **Registro Automatizado:** Incremento automático de +100 puntos en el perfil del usuario cada vez que se invoca un evento de victoria legítimo.
* **Independencia de Código:** Modularidad completa implementada en un único archivo ejecutable (`Partida.java`) para facilitar la fusión de ramas sin conflictos.

## 💻 Instrucciones de Ejecución

Para ejecutar y probar este sistema localmente, asegúrate de tener instalado el Java Development Kit (JDK) y sigue estos pasos:

1. Abre el proyecto en tu IDE preferido (como Visual Studio Code o NetBeans).
2. Dirígete al archivo `Partida.java`.
3. Haz clic en el botón **Run** (Ejecutar) situado sobre el método principal `main`.
4. Verifica los resultados impresos en la consola del sistema.
